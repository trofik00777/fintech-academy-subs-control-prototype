# ВТБ · Контроль подписок

Интерактивный PWA-прототип сервиса по [ТЗ](./description_tech.md), оформленный по референсам из `template/`. Только интерфейс сервиса; данные, платежи, уведомления и действия с поставщиками имитируются.

## Запуск

Нужен Node.js 20 или новее. Внешних зависимостей нет.

```sh
npm run dev
```

Открыть http://localhost:5173. Для просмотра с телефона в той же сети используйте адрес компьютера и порт 5173. Установка PWA и офлайн-режим доступны на localhost или при размещении через HTTPS.

```sh
npm test          # Проверка финансовой логики
npm run build    # Статическая сборка в dist/
npm run preview  # Просмотр сборки
```

## Демонстрация

Кнопка **Демо-сценарии** в верхней панели открывает шесть подготовленных ситуаций. На телефоне это кнопка с треугольником. Каждый сценарий сбрасывает данные; кнопка **Сбросить всё** также возвращает исходное состояние.

1. **Оплата с подтверждением:** открыть уведомление Иви → подтвердить → увидеть результат и запись в истории.
2. **Повышение цены:** Яндекс Плюс, 299 → 449 ₽ при лимите 350 ₽ → дать разовое согласие, перенести или заблокировать платёж.
3. **Лимит:** МТС, 890 ₽ при лимите 700 ₽ → проверить автооплату → увидеть остановку. В деталях можно изменить лимит или режим оплаты.
4. **Бюджет:** до 20 октября запланировано 3 077 ₽ при бюджете 2 500 ₽. Перенос FitStars на 20 октября меняет прогноз с −577 ₽ на +613 ₽.
5. **Автооплата:** iCloud+ → проверить автооплату → оплата в рамках лимита и бюджета.
6. **Отказ от подписки:** в деталях FitStars можно отдельно заблокировать один платёж или отключить подписку целиком.

Дополнительно доступны календарь, история, поиск и фильтры, настройки напоминаний, изменение бюджета и даты дохода, возобновление подписки, добавление Яндекс 360 из тестовой истории повторяющихся списаний.

## Правила демо

- Дата фиксирована: **8 октября 2026**.
- Состояние сохраняется в `localStorage` текущего браузера.
- Доступный бюджет = бюджет периода − уже оплаченные в демо подписки. Прогноз = доступный бюджет − активные незаблокированные платежи до даты дохода; день дохода относится к следующему периоду.
- Успешная демо-оплата добавляет событие в историю и переносит следующее списание на месяц. Разовое согласие не увеличивает лимит.
- Блокировка исключает ближайший платёж, сохраняя подписку и месячные расходы. Отключение исключает все будущие платежи и месячную стоимость.
- Перенос даты и отмена у внешнего сервиса — предполагаемые сценарии, их ограничения обозначены в соответствующих диалогах.
- Все ресурсы локальные. Service worker кеширует интерфейс для работы без сети после первого открытия.

## Структура

`src/model.js` — данные и финансовая логика; `src/app.js` — экраны и действия; `src/styles.css` — адаптивное оформление; `sw.js` и `manifest.webmanifest` — PWA; `tests/model.test.mjs` — проверки сценариев. `scripts/server.mjs` — только сервер статических файлов для разработки, без API и бэкенда.
